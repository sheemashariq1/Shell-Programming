## 🖥️ How to Run & View Output

Each `.sh` file in this repo is a standalone script. To run any of them:

```bash
chmod +x filename.sh
./filename.sh
```

Example:

```bash
$ ./Test.sh
Enter your name: Sheema
Hello Sheema, we will now start Shell Programming!
```
